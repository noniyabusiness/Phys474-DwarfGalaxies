# Phys474-DwarfGalaxies
Data availability:

This project uses publicly available data from the IllustrisTNG TNG50-1 simulation, primarily snapshot 91 ((z\approx0.1)).

The large halo and subhalo catalogue files used during the analysis are not included in this repository due to their size. These data can be accessed through the IllustrisTNG public data release.

The repository contains the analysis code and selected derived results.
